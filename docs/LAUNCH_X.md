**1/**

I built threadterm — Threads in your terminal.

TUI like tut/lazygit.
CLI for agents (`--json`).
Demo mode works offline.
Live mode uses Meta’s official API.

github.com/arifaqyl/threadterm

**2/**

Why?

Phone apps are slow for power users.
Existing Threads CLIs are thin.
Nobody shipped a polished Bubble Tea client that also speaks JSON to agents.

**3/**

```

threadterm --demo
```
